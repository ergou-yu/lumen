# Lumen · 私人 AI 代理

> 印象派风格的开源 Personal Agent —— 独立设计 · 零依赖 · 数据全在本地
>
> **让光为你做事。**

Lumen 是一个原创开源的私人 AI 代理：不只是聊天机器人，而是一位**替你把事情办成**的私人助理。它运行在莫奈《睡莲》般的点彩水面上，头像就是莫奈真迹，接得住任何一家大模型，还能通过内置技能库**真实操作你的电脑**。

## 🚀 30 秒上手

```bash
git clone https://github.com/ergou-yu/lumen.git
cd lumen
node server.js        # 一条命令：启动本地网址 + 技能库 + 虚拟计算机桥
                       # 会自动打开浏览器；不想自动开：LUMEN_NO_OPEN=1 node server.js
```

**运行要求**：Node ≥ 18（唯一必需，零 npm 依赖）。可选项按需开启——

| 可选组件 | 用途 | 开启方式 |
|---|---|---|
| Docker Desktop | LumenBox Desktop 桌面虚拟机（GUI 任务 + Live 画面） | 安装并启动 Docker 即可，首次启动自动构建镜像 |
| 任意模型 API Key | 基础模型（六家厂商或自定义端点，自带 Key） | 设置 → 模型接入，填入你自己的 Key |
| 任意 OpenAI 兼容 Key | 换用其他模型 | 设置 → 模型接入 |
| qcu CLI | 「用我的电脑」真机操作流 | `pip install -e quick-computer-use` |

> 克隆后无任何个人数据：工作区、凭证安全区、任务状态都是首次运行时自动生成的空文件。

打开的就是本地网址 **http://127.0.0.1:8787** —— 应用、技能、电脑操作、虚拟计算机全部同源，没有 CORS 顾虑。

- **不启动服务桥**也能用：直接双击 `index.html`（file://）进入演示模式；技能与 QCU 需要服务桥。
- **启动后**：设置 → 模型接入 → 挑一家（OpenAI / Claude / Gemini / 智谱 / DeepSeek / Kimi / 通义 / 自定义 OpenAI 兼容端点）→ 填入**你自己的 API Key** → 测试连接 → 启用。也可以先用演示模式逛逛。
- 换端口：`PORT=9000 node server.js`。诊断页：`/healthz`。
- 注意：之前的 `python3 -m http.server` 方案已不需要——服务桥自己就是静态服务器，而且比它多出技能/QCU/虚拟计算机三样。

## ✨ 核心机制

- **动作审批（Approval）**：花钱、预订、对外发送等关键动作前，代理会暂停并弹出审批卡——**允许一次 / 总是允许 / 拒绝**。拒绝则任务立即停止，绝不先斩后奏。
- **自主程度**：设置里可选 `每次都问` / `仅敏感操作`（默认，推荐）/ `全自动`。全自动不弹卡，但每一步仍写入审计日志。
- **审计日志（Audit Trail）**：代理做过的每一件事、每一次批准与拒绝，全部留痕，设置面板随时可查。
- **后台继续工作**：切到其他 Tab 或页面，任务继续执行；导航徽标会提示新成果。
- **可中断**：随时按停止键，连挂起中的审批卡也会一并处理，不会卡死。
- **并行任务**：不必等上一件事做完，随时下发自任务（非回合制体验）。

## 🖥 虚拟计算机（LumenBox）：Lumi 自己的电脑

Lumen 的核心设计之一：**代理在一台属于它自己的虚拟计算机上干活，而不是操控用户的电脑**。它叫 **LumenBox**，由本地服务桥提供（`node server.js` 后自动可用）：

```
对 Lumi 说「上网查一下…」「打开这个网页…」
  → 唤醒虚拟计算机 → 模型规划浏览动作 → 虚拟浏览器真实执行（检索 / 打开 / 点链接 / 阅读）
  → 证据注入作答 → 浏览笔记自动存进工作区 notes/
```

- **虚拟浏览器（真实执行）**：服务桥进程内的浏览器——真实检索（DDG/Bing/百度多引擎）、真实打开网页、按编号点链接、整页阅读。它有地址栏、历史、当前页，全在「**计算机**」页可视化，你可以点链接陪它一起逛。
- **囚笼工作区 `vm-home/`**：Lumi 的文件全部落在这里（路径穿越一律拒绝），可查看、**在线编辑**、下载、上传、删除、一键清空；重启后保留。
- **文件双向通道**：①「上传文件到虚拟机」——本地文件直接进工作区，代理与虚拟机浏览器都能用；② **下载直通**——桌面虚拟机里浏览器下载的文件自动落到工作区（容器 Downloads 与 vm-home 同一目录），「计算机」页实时可见、随取随用。
- **无需逐步审批**：浏览发生在隔离环境里，碰不到你的本机，所以不弹审批卡——但每一步都写入审计日志（在自己的电脑上自由干活，越界才需要批准）。
- **真机操作是例外**：说「**用我的电脑**…」「在这台电脑上…」时才走 QCU 真机流（无障碍树观察→规划→**批准**→执行）；也可在 设置 → 虚拟计算机 里关掉「优先在虚拟计算机」。
- **虚拟终端（可选，默认关）**：软沙箱——命令真实运行于本机，仅工作目录与 HOME 被钉在 `vm-home/`，**不是系统级隔离**；要求硬隔离可设 `LUMEN_VM_SHELL=0` 彻底禁用。开启前设置页会明确提示边界。
- API：`POST /vm/exec`（browser: state/search/open/click/read/back · files: ls/read/write/rm/clear · shell: run）· `GET /vm/state` · `GET /vm/file/<name>`。

> 诚实边界：LumenBox 轻量版是「服务桥内的虚拟浏览器 + 囚笼文件系统」；浏览以正文阅读视图呈现，不执行页面 JS。GUI 级的完整桌面虚拟机见下一节 **LumenBox Desktop**。

## 🏰 LumenBox Desktop：容器化桌面虚拟机（Sentinel 全程审查）

Lumen 桌面虚拟机的完整形态——**Lumi 拥有一台真正的「电脑」**：本机 Docker 里的非特权 Linux 容器，完整桌面 + 真实 Chromium，你可以**实时观看它干活、随时接管**。需要 Docker Desktop（首次启动自动构建镜像）。

| 设计原则 | LumenBox Desktop 的实现 |
|---|---|
| 每用户一台隔离虚拟机（专属浏览器/文件系统/终端） | `vm-box/` 镜像：Xvfb 桌面 + openbox + 真实 Chromium + VNC；Cookie/历史保存在私有卷 `lumen-box-home`，与宿主隔离 |
| 容器而非完整硬件虚拟机（最小能力、系统调用受限） | Docker 非特权容器：`--cap-drop ALL`、`no-new-privileges`、pids/memory 限额、tmpfs /tmp |
| 审批权威（Sentinel）跑在容器外，Agent 碰不到关不掉 | Sentinel 规则引擎在宿主 server.js 里：每个动作先判 **放行 / 阻止 / 请示你**；批准一次发 **10 分钟能力凭证**（同类动作不再打扰） |
| 出网审查：目标地址 + 恶意站点名单 + SSRF 拦截 | 导航审查：私网/回环地址一律拦截（SSRF），内置恶意站点名单（`vm-denylist.txt` 可自行追加） |
| 支付/发邮件等敏感动作必须用户确认并留审计 | 点击「支付/下单/发送/登录」类按钮、向密码/卡号字段输入 → 强制审批卡；全程审计 |
| 凭证存独立安全区，模型看不到明文，获批后由出口注入 | 凭证安全区 `lumen-vault.json`（0600）：**值只进不出**——模型只能按名称引用，获批后由服务桥直注虚拟机键盘，明文不进上下文/快照/日志 |
| 浏览器防护：模型只读元素清单，不执行页面 JS | 模型看到的是元素清单（编号/文本/坐标），非原始 DOM；动作经 xdotool 真实注入 |
| 用户可实时观看/接管代理的电脑 | 「计算机」页内嵌 noVNC **Live 画面**——看它操作，也能直接接管（你在画面里动手时，Lumi 下一步会先重新观察） |
| VM 内文件可查看/编辑/下载/上传 | 工作区在线编辑、上传、下载、删除、一键清空；容器浏览器下载直通工作区（中文名完整保留） |
| 应用只是遥控器：任务在宿主执行，关页继续跑 | 桌面任务循环跑在**服务桥（宿主）**里，关掉浏览器照常执行；回「计算机」页看进度与审计 |

使用：对 Lumi 说「**打开 xx 网站帮我登录/下单/比价**」这类 GUI 任务，或到「计算机」页手动启动 → 在 Live 画面里看它工作。设置 → 虚拟计算机里可选桌面模式（自动 / 总是 / 关闭）并管理**凭证安全区**。

技术：镜像 `docker build -t lumen-box vm-box/`（启动时自动完成）· 容器内控制服务只收指令（观察/截图/输入注入），**没有任何审批与凭证逻辑**——安全层全部在宿主，容器被攻破也拿不到凭证。桌面任务 API：`POST /vm/desktop/tasks`（服务端执行）· 审批 `/sentinel/decide`、`/vm/desktop/tasks/:id/approve` · 安全区 `/vm/vault`（只回名称）。

> 边界：Docker 容器提供**操作系统级隔离**（远强于轻量沙箱终端），但未实现内核级污点追踪（以动作级风险分类近似「读过敏感数据 ⇒ 需审批」）；浏览器凭据填写不执行页面 JS 注入，而是真实键入；Confidential VM（整机加密）暂未实现。

## 📱 手机访问（同一 WiFi 遥控）

任务都在服务桥执行，手机只是另一块遥控屏：

```bash
LUMEN_HOST=0.0.0.0 node server.js   # 或 LUMEN_HOST=0.0.0.0 sh run.sh
```

然后手机连同一 WiFi，浏览器打开 `http://<电脑局域网IP>:8787`（设置 → 手机访问会列出现成地址，Mac 还会给出 `http://<主机名>.local:8787`，iPhone 无需记 IP 直接可用）。应用本身是响应式的（底部 Tab 导航）；Live 画面在手机上也可观看与接管。⚠️ 仅在可信 WiFi 下开放：局域网内设备都能触达服务桥（含安全区接口），公网暴露请勿使用。

### iPhone 一分钟上手

设置 → 手机访问卡片里有**二维码**（零依赖手写编码器生成，扫码直达）：

1. iPhone 相机扫码 → Safari 打开 Lumen；
2. Safari 底部「分享」→「添加到主屏幕」；
3. 之后从主屏幕图标进入，全屏运行、独立图标，像原生 App 一样，不用再记地址。

安卓同理：Chrome 打开地址 → 菜单「添加到主屏幕」。注：iOS 对 `http://` 页面不提供 Web 通知，任务完成通知在该场景下依赖 Webhook 渠道。

## 🔗 应用连接（飞书 / Google / Amazon）

第三方应用一律**自带凭证**，密钥只存本机 `lumen-connectors.json`（0600，已 gitignore），API 永不回传明文。在 设置 → 应用连接 配置：

- **飞书 / Lark**——两种连法：① 群机器人 Webhook（群里加「自定义机器人」，30 秒搞定，能发群消息）；② 企业自建应用（App ID/Secret，能发消息、建文档、建日程）。配好后直接说「飞书发：今晚 8 点开会」「把这份笔记存到飞书文档」，经你批准后真实发送。
- **Google Gmail / 日历**——Google Cloud 建 OAuth 客户端（桌面应用类型），填 Client ID/Secret 点一次「去授权」（回调走本机 localhost，支持自动刷新 token）。之后「发邮件给 xx@xx.com 主题… 内容…」「谷歌日历加个日程 周五 3 点牙医」都是真发真建。
- **Amazon**——亚马逊不对个人开放下单 API，所以不做假接口：点「派 Lumi 去虚拟机逛 Amazon」，它在桌面虚拟机的真实浏览器里比价、加购物车，登录凭证走「凭证安全区」，付款前每步经 Sentinel 请示。

所有对外发送类动作默认走审批门（尊重规则引擎的 允许/先问/转交 三态与自主程度设置），失败时如实报告上游错误，绝不假装成功。

### 🖥 电脑操作（虚拟计算机优先 · QCU 真机为辅）

对 Lumi 说「**上网查一下…/帮我打开这个网页…**」会触发**虚拟计算机流**（默认，不碰你的电脑）：

```
唤醒 LumenBox → 模型规划浏览动作 → 虚拟浏览器真实执行（检索/打开/点链接）→ 阅读取证 → 笔记存入 vm-home/
```

- 浏览在隔离环境内进行，**无需逐步审批**，但每步写审计日志；成果见「计算机」页。
- 对 Lumi 说「**用我的电脑…/帮我点一下……/屏幕上……**」则触发 **QCU 真机流**（观察→规划→**你批准**→执行→复核）：

```
qcu session start → observe（无障碍树）→ 模型规划动作 → 你批准 → qcu act → observe 复核 → session end
```

- 观察与规划自动进行；**执行任何动作前必须经你批准**（除非你选过「总是允许」或全自动模式）。
- QCU 用无障碍树 ref 定位控件而非截图坐标，动作可验证、不盲点。
- 演示模式（未接模型）只观察不执行；接入模型后才规划真实动作。
- 需要：本机已安装 `qcu` CLI（`pip install -e quick-computer-use`）且本地服务桥在运行。

### 🔌 服务端模型（可选，自带 Key）

聊天用的模型密钥**只存在你本机浏览器**（localStorage），浏览器直连各厂商。只有两类服务侧功能需要服务端也能调用模型——**桌面虚拟机任务**与**监控命中判断**。若需要，用环境变量提供你自己的密钥与端点（任意 Anthropic 兼容网关）：

```bash
LUMEN_MODEL_API_KEY=你的Key \
LUMEN_MODEL_BASE=https://你的端点/api/anthropic \
LUMEN_MODEL_NAME=模型名 \
node server.js
```

- 未配置时：聊天与全部浏览功能照常（浏览器直连），桌面任务与监控智能判断优雅降级并如实提示。
- 附赠通用本地网关：配置后 `http://127.0.0.1:8787/v1` 提供 Anthropic 透传 + OpenAI 协议转译——**你选的端点不支持浏览器 CORS 时**，在设置 → 模型接入 → 「本地网关」填这个地址即可接入（密钥走环境变量，不进页面）。
- 密钥只来自环境变量：Lumen **不读取任何第三方工具的本地配置文件**。

> **CORS 小贴士**：个别服务商不允许 `file://` 或 `null` Origin 直连。若「测试连接」报网络错误，改用 `node server.js` 从 **http://127.0.0.1:8787** 打开即可（localhost Origin 通常放行）。

## 🎨 莫奈印象派设计系统

视觉与动效全部来自 `motion-skill-kit`（前端艺术动效片段库）的经过验证的片段，性能预算遵守「全页 high 特效 ≤1、medium ≤2」：

| 片段 | 用在哪 | 说明 |
|---|---|---|
| `impressionism` 莫奈点彩水面 | 全站背景 | canvas 互补色并置点彩（蓝↔橙、紫↔黄绿），画「光的变化」而非轮廓，持续缓慢演化 |
| `per-char-reveal` 逐字入场 | 欢迎语 | 每字 35ms stagger，从雾中浮现 |
| `fade-slide-route` 路由转场 | 五个 Tab 切换 | 淡入 + 上滑 + 模糊收束 |
| `ken-burns` 缓放 | 动态/文件卡片封面 | 慢到不被察觉的呼吸缩放 |
| `noise-grain` 噪点颗粒 | 全站顶层 | feTurbulence 胶片颗粒，打破数字塑料感 |

所有动效均保留 `prefers-reduced-motion` 降级：背景画完即定格成交品、文字直接呈现、转场直接切换。

「文件」页的**生成画作**用的是与背景同一支画笔（`MonetBG.paintPicture`），每幅仅此一张。
