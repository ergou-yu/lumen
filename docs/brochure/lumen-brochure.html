I. 它是什么

壹 · 一位替你办事的代理

与聊天机器人的分野在于：旧式助手帮你「想和答」，Lumen 帮你「做」。你给出目标，它自主拆解任务、 联网取证、生成文件、操作电脑，在敏感节点把决定权交还给你——像一位私人助理，亲自去买回来再向你汇报。

七个页面，一位代理Seven Rooms

聊天Chat

主入口。任务分解活动卡、虚拟浏览器小剧场、流式回答，可中断、可并行多个任务。

动态For You

兴趣自选的简报流：每日简报、可一键委托的资讯卡、监控命中提醒、成果回顾。

灵感Ideas

十五张点子卡（效率、生活、创作、学习、理财），点击即作为任务发给代理。

目标Goals

从对话沉淀的长线目标：自动建档、拆步骤、跟进进度；底部是后台监控任务区。

文件Files

代理生成的真实产物：研究报告、日历事件、邮件草稿、即兴画作，皆可下载。

记忆Memory

它记住的关于你的一切：偏好、事实、关系、习惯——可查看、编辑、遗忘。

技能Skills

十项内置技能库：启停即生效，启用后作为代理的专业知识注入每一次对话；其中电脑操作技能可经本地桥真实驱动你的电脑。

它的身世Lineage

产品包含五大导航页与一整套可信机制：任务审批、审计日志、 常驻任务、长期记忆一一对应；并在其上长出自己的枝叶——莫奈印象派视觉与本地优先的隐私立场。

如何运行To Run

零依赖、零构建。一条命令 node server.js 即得到本地网址 http://127.0.0.1:8787：应用、模型反代、技能服务、电脑操作桥同源一体， 只监听本机，绝不出网。

II. 核心体验

贰 · 交付决定权在你

Lumen 的每一次行动都看得见、管得住、查得到。

任务剧场The Task Theater　透明执行

理解意图识别八类任务
制定计划拆解可见步骤
逐步执行进度实时可见
交付结果产物归档文件页

执行过程以活动卡呈现：每一步的状态、检索的关键词、正在阅读的网页地址，全部实时展示——代理在它的虚拟计算机上干活，你隔着玻璃看。

关键动作审批Approval　人在环

花钱、预订、对外发送、操作你的电脑——四类敏感动作执行前必须经你批准：

  • 允许一次：仅此一回
  • 总是允许：此类操作此后自动放行
  • 拒绝：任务立刻停下，绝不先斩后奏

自主程度三档可选：每次都问／仅敏感操作（推荐）／全自动（只记日志不弹窗）。

审计日志Audit Trail

代理做过什么、凭什么做的、结果如何——每一步都留痕：检索了什么、批准了什么、生成了什么， 设置面板随时回查，可导出。

中断与并行Interrupt

非回合制：不必等一件事做完，随时下达新任务（并行推进），也随时按停——连挂起中的审批卡都会一并妥处，不会卡死。

切页不打断Background　后台继续

浏览其他页面甚至切换应用，任务在后台继续执行；导航徽标与动态页会告诉你新的成果何时落成。

聊天页内亦然：研究进行到一半可以追加要求，审批卡挂着的同时先聊别的，回来时进度仍在向前——你从不必为一个任务守在原地。新成果落成时，聊天页徽标亮起、动态页同步生成回顾卡。

III. 真实能力

叁 · 不演给你看

接入模型后，以下能力全部真实——检索是真的，文档是真的，日历与邮件是真的，鼠标也是真的。

联网研究管线Live Research　真实检索

生成搜索词提炼中英双语关键词
多引擎检索三个引擎递进，广告过滤、相关度打分
阅读来源抓取正文，提取证据
引证作答标注来源编号，查不到就明说

证据皆带来源编号，说话有出处；三十分钟查询缓存，对公共搜索引擎温柔以待。

真实产物Artifacts

  • 研究报告——模型回答全文，含真实来源链接，存为文档
  • 日历事件——标准 .ics，下载双击即入系统日历
  • 邮件草稿——标准 .eml，导入邮件客户端可编辑发送
  • 即兴画作——本地印象派点彩，每幅仅此一张

电脑操作Computer Use　逐步请示

观察无障碍树
规划模型定动作
批准由你放行
执行真实点击

基于 QCU 技能：以无障碍引用定位控件而非截图坐标，动作可验证、不盲点。演示模式只观察不动手。

诚实清单Honest Edges

不替你付款，不替你发送——最后一步永远由你完成，或让代理用电脑操作陪你走到下单页（每步仍会请示）。

  • 查无实据即坦言「未检索到」，绝不编造价格、库存与航班号
  • 公共搜索引擎偶有限流，检索步骤如实标注「受限」，绝不假装成功
  • 演示与真实两种模式，界面永远如实标注当前所在

IV. 常驻与记忆

肆 · 关掉页面，它还在

「云端电脑」式的能力，在 Lumen 里由本地服务桥兑现——浏览器只是遥控器。

七乘二十四小时监控Always-On Watch　常驻任务

说一句「帮我盯着机票降价、演出开票、申请开放」，代理便在服务桥注册常驻任务：

注册本地服务桥接管
巡检定时真实检索
判断模型识别命中
通报命中卡即时生成

任务持久化在磁盘上——关掉浏览器、合上笔记本再打开，它照常运转。命中的动静出现在目标页监控区与动态页命中卡，节奏可暂停、可删除。

长期记忆Memory

每次对话后自动沉淀值得记住的偏好、事实、关系与习惯（自动去重），并注入之后每一次对话，越用越懂你。 记忆页里每一条都可查看、编辑、遗忘，也可手动记一条。你的记忆文件，主权在你。

个性化Persona

名字随你起；三幅莫奈真迹头像任选；三种说话方式——温柔印象派、简洁高效、热心絮叨—— 连朗读语速都会随之变化。

语音模式Voice

输入：对着麦克风说，中文识别直达输入框。输出：可开启回复朗读。

用量计Usage

设置页内置用量统计，花销透明，心中有线：

  • 调用次数——按日累计，今日多少一目了然
  • token 估算——输入、输出、合计三口径，皆可回查
  • 近七日条形图——每日用量起伏，一眼看清
